# TubePlayer

A single-page site: paste a YouTube link, the video pops up and plays right there.

## Usage

Just open `index.html` in a browser (or serve the folder with any static file server). Paste a `youtube.com`, `youtu.be`, or Shorts link into the box and hit **Play**.

No backend, no build step — it's a static page that embeds YouTube's official player.

Search

One-time setup: search needs a free API key from Google so this page can ask YouTube for results.
  1. Go to console.cloud.google.com and sign in with any Google account
  2. Create a new project (any name is fine)
  3. Search for and enable the "YouTube Data API v3"
  4. Go to APIs & Services → Credentials → Create Credentials → API key
  5. Copy the key it gives you and paste it below
Saved. You can search now.
